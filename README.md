# MATH 2001 Problems
Some problems and solutions as I work through learning how to write mathematical proofs with a proof assistant.

Problems are mostly from [Heather Macbeth's _The Mechanics of Proof_](https://hrmacbeth.github.io/math2001/).
Some problems may also be from [Mathematical Proofs: A Transition to Advanced Mathematics, 4th edition](https://www.pearson.com/en-us/subject-catalog/p/mathematical-proofs-a-transition-to-advanced-mathematics/P200000006146/9780137981731).
